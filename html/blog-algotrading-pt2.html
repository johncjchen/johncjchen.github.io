Algotrading Parameter Optimization and Selection: Initial Steps (Pt. 2)

November 17, 2025 Finance & Trading • 5 min read

Welcome back to part two in my series of discovering the optimal set of strategy parameters that is both robust and survivable in the uncharted waters of the future market.

Let's start with covering some of the basic groundwork. As I mentioned in Part 1, I will be using Python and the backtesting.py library with the assistance of Claude Code to develop and test my strategy. The yfinance library will be utilized for retrieving historical data from Yahoo Finance's API. I won't go over the strategy I'm actually developing, but let's just make one up right now. It could be a banger.

The Strategy

The strategy will be very simple. We will use simple moving averages (SMA) crossovers for entry/exit signals and also add a simple momentum entry signal. Momentum-wise, the strategy will simply count the number of green bars and enter after a threshold has been reached.

Signals from SMA crossovers are simple and relatively reliable; although, they may be prone to noise and are, by nature, lagging indicators, which may present problems in the future. Counting green bars is simple enough but does provide a separate complexity to the strategy, which we will explore later in parameter set determination.

Testing Environment

Backtesting will be done on TQQQ, a 3x leveraged version of QQQ. There are caveats to holding or trading TQQQ past intraday speculation, but I am going with this ticker to magnify returns. It's fun to see big numbers. Black swans can also be catastrophic. The timeframe will be daily bars since yfinance will be able to get the most amount of data points with daily bars in addition to the exposure with disparate market regimes (bull, chop, and bear).

The Code

Below is the code for the strategy described above written for the backtesting.py framework.

class SMAMomentumStrategy(Strategy): """ SMA Crossover + Green Bar Momentum Strategy Parameters: - fast_sma: Period for fast moving average - slow_sma: Period for slow moving average - green_bar_threshold: Number of green bars required for momentum confirmation """ # Strategy parameters fast_sma = 10 slow_sma = 30 green_bar_threshold = 3 def init(self): # Calculate SMAs self.sma_fast = self.I(lambda x: pd.Series(x).rolling(self.fast_sma).mean(), self.data.Close) self.sma_slow = self.I(lambda x: pd.Series(x).rolling(self.slow_sma).mean(), self.data.Close) # Calculate green bar indicator (Close > Open) self.green_bars = self.I(self._count_green_bars, self.data.Close, self.data.Open) def _count_green_bars(self, close, open_): """Count consecutive green bars (close > open)""" green = (close > open_).astype(int) # Count consecutive green bars counts = np.zeros(len(green)) count = 0 for i in range(len(green)): if green[i] == 1: count += 1 else: count = 0 counts[i] = count return counts def next(self): # Skip if we don't have enough data if len(self.data) < self.slow_sma: return # Check for SMA crossover sma_bullish = crossover(self.sma_fast, self.sma_slow) sma_bearish = crossover(self.sma_slow, self.sma_fast) # Check momentum condition (green bar count) momentum_confirmed = self.green_bars[-1] >= self.green_bar_threshold # Current trend state uptrend = self.sma_fast[-1] > self.sma_slow[-1] # Entry logic if not self.position: # Enter when SMA crosses bullish AND momentum is confirmed if sma_bullish and momentum_confirmed: self.buy() # Alternative: Enter on uptrend with fresh momentum confirmation elif uptrend and momentum_confirmed and self.green_bars[-2] < self.green_bar_threshold: self.buy() # Exit logic else: # Exit on bearish crossover if sma_bearish: self.position.close()
